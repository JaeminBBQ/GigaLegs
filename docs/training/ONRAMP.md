# On-Ramp: 3 Weeks Before Program Week 1

**Purpose:** get muscles, tendons, and technique re-accustomed to the program's movements and volume *without* the 1–2 week soreness crater that comes from starting cold at full loads. Repeated-bout effect: a few progressively harder exposures to the same movements dramatically reduce later DOMS.

**Start date:** set by the athlete (proposed: week of 2026-10-05). Program Week 1 then starts ~2026-10-26.

## Rule of thumb
Use the program's **Week 1** sessions (same exercises, same days) and scale them:

| On-ramp week | Load (% of program Week 1 working weight) | Sets (% of prescribed) | RPE cap | Accessories |
|---|---|---|---|---|
| A | 60% | 50% | 6 | 1–2 easy sets each |
| B | 75% | 70% | 7 | 2 sets each |
| C | 90% | 100% | 8 | As written |

- Sets: round up, minimum 2 (a single prescribed set stays 1), never more than prescribed.
- RPE cap = the lower of the table cap and (program target RPE − 1).
- Reps stay as written.
- Round loads to the nearest 5 lb.
- If a session lists RPE instead of a weight, use the RPE cap from the table instead.
- Warm up with 2–4 ramping sets before the first working set on squat/deadlift.

## Gate to advance each week
Advance from A→B→C→Program only if:
- leg soreness at the next session is ≤ 5/10, **and**
- no joint pain, **and**
- every working set was at or under the RPE cap with solid form.

Otherwise **repeat the week** (that's still progress — it earns XP, see GAMIFICATION).

## Biking during the on-ramp
See `BIKE_COMMUTE_PLAN.md` Stage 1: 2–3 easy rides/week, 20–45 min, flat routes, on non-lifting days or after lifting.

## Example (illustrative only; replace with real numbers once the lb sheet and maxes are in, see `handoffs/HUMAN.md`)
If program Week 1 says back squat 4×5 @ 225 lb:
- Week A: 2×5 @ 135 (60% = 135)
- Week B: 3×5 @ 170 (75% ≈ 169 → 170)
- Week C: 4×5 @ 205 (90% ≈ 203 → 205)
- Program Week 1: 4×5 @ 225
